# LogoStyler — frontend

Клиентская часть «Сервиса подготовки логотипов под единый стандарт размещения на сайте»:
экран создания шаблона плашки и редактор, открываемый по ссылке (загрузка логотипа, обрезка,
масштаб, перемещение, центрирование, предпросмотр, экспорт).

Проектный практикум УрФУ; трекер — Jira, проект `LOGO`.

Глоссарий, функциональные требования `F-01…F-19`, критерии приёмки `AC-01…AC-14`, формат ссылки
и правила этого каталога — в [AGENT.md](AGENT.md).

## Зачем это нужно

Карточки в разделах «Партнёры» и «Участники» имеют одинаковый контейнер, но присылаемые логотипы
различаются по полям и качеству: если вокруг логотипа остаются большие белые или прозрачные поля,
он занимает малую часть плашки и карточки выглядят неравномерно. **Ключевой принцип:** сервис
стандартизирует не размер файла, а размещение *видимой части* логотипа внутри заданной плашки;
пропорции при этом сохраняются.

## Экраны и маршруты

| Маршрут | Экран |
|---|---|
| `/` | создание шаблона: ширина и высота плашки, цвет фона (по умолчанию `#FFFFFF`), охранные отступы, формат экспорта, ссылка |
| `/t/:templateId` | редактор по ссылке: загрузка SVG/PNG/JPG, автообрезка или ручная обрезка, вписывание и центрирование, масштаб, перемещение с направляющими, предпросмотр, экспорт |
| `*` | страница «не найдено» |

Параметры шаблона сейчас передаются в query-строке ссылки:
`/t/demo?w=400&h=220&bg=%23FFFFFF&p=20&fmt=png` (`w`, `h` — размеры плашки в px, `bg` — фон,
`p` — охранные отступы или `pt`/`pr`/`pb`/`pl` по сторонам, `fmt` — формат экспорта).
Разбор — в `src/lib/templateParams.ts`, сборка ссылки — `buildEditorHref` в `src/lib/routes.ts`.

## Стек

React 19, TypeScript, Vite, react-router 8, Tailwind CSS 4, shadcn на `@base-ui/react`,
Konva + `react-konva` + `use-image` (сцена редактора и экспорт через Canvas), `react-easy-crop`,
`dompurify` (безопасный SVG), Zustand (состояние редактора), Sonner (уведомления).

Целевые браузеры — актуальные Chrome, Edge, Firefox на ПК. Базовый лейаут рассчитан на ширину
от 1280 px: на более узких экранах появляется горизонтальная прокрутка, мобильной версии нет.

## Команды

```bash
npm install        # зависимости
npm run dev        # dev-сервер Vite
npm run build      # tsc -b && vite build
npm run preview    # предпросмотр собранного бандла
npm run lint       # oxlint
npm run format     # biome format ./src
```
